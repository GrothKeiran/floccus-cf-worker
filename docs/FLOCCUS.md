# 在 Floccus 中连接与处理首次同步

## 1. 准备

安装官方 Floccus，先导出浏览器现有书签作为备份。按[账户教程](ACCOUNTS.md)创建用户，并给当前浏览器签发**独立**的应用密码。

## 2. 添加 WebDAV 账户

| 配置项 | 内容 |
|---|---|
| 后端 | **WebDAV**，不是 Nextcloud Bookmarks |
| 预定义服务器 | 自定义服务器 / Custom Server URL |
| WebDAV URL | 自己的 HTTPS Worker 根地址 + `/dav/` |
| 用户名 | 自己创建的用户名，例如 `owner` |
| 第一个密码框（认证密码） | 该设备的 `applicationPassword`，完整保留 `app_` 前缀 |
| 书签文件名 / 路径 | `bookmarks.xbel`，不要有前导 `/` |
| 文件类型 | XBEL |
| 第二个密码框 / 加密口令 / Passphrase | **留空** |
| 客户端凭据 / Client credentials | 一般保持默认关闭；本服务不使用客户端证书或 Cookie 认证 |

不要把 `/health/ready` 填作 WebDAV URL，也不要在 URL 后再次拼入文件名。加密口令不为空时，Floccus 会上传加密文件，本项目无法把它解析为 XBEL。

## 3. 目录映射与策略

- Chrome 选原生“书签栏”；Edge 选“收藏夹栏”；Firefox 选“书签工具栏”。不是新建一个同名普通文件夹。
- 默认选择“始终将本地更改与其他浏览器的更改合并”。服务器不强行把最新时间戳当作胜者。
- 保持安全保护开启。第一台完成首次同步后再配置下一台，避免首次导入互相打断。
- 多台设备使用相同用户名、WebDAV URL 和文件名，但应用密码不同。
- 普通使用可先设 15～30 分钟定时同步；改变书签、手动同步和重试还可能额外触发请求，不是“15 分钟只消耗一次 Worker 请求”。

不要在一个设备选整个浏览器根目录、另一个设备只选书签栏，却期望完全相同的目录结构。切换同步根前先备份并规划新的基线。

## 4. E043：服务器书签数量将增加较大比例

这是 Floccus 的**大比例新增安全保护**，不是 Cloudflare 额度耗尽或密码错误。它表示本轮计划新增较多，不能据此认定上传已完成。第二个浏览器有独有书签、选错根目录或存在重复同步配置时，都需要先核对，而不是直接长期关闭保护。

先确认两端映射都是正确原生目录，并导出书签备份，然后根据目标选择：

### 两边原有书签都要保留

保持双向合并。只有确认新增是自己想要的后，才考虑在当前配置中暂停自动同步，进入“危险行为 → 安全保护”临时关闭保护，手动合并一次，完成后立即重新开启安全保护和自动同步。

这个开关同时影响大量添加与删除；不要为了消除错误而永久关闭。若不确定新增来源，先不要继续。

### 以云端已有书签为准

在已有备份、确认云端内容完整后，选择手动操作中的“拉取一次 / 从服务器覆盖本地”。它可能删除本机同步目录中云端没有的书签。

不要误选“推送一次”，后者是本地覆盖远端。一次性操作完成后，日常仍保持双向合并，不要把长期策略改成单向覆盖来掩盖问题。

## 5. 常见错误

| 现象 | 检查内容 |
|---|---|
| 401 | 用户名、该设备应用密码、是否被撤销；不要填账户密码或管理员 Token |
| 404 | URL 是否以 `/dav/` 结尾、文件名是否为 `bookmarks.xbel`；初次远端文件尚不存在时的 404 可由扩展处理 |
| 413 | XBEL 超过 `MAX_BODY_BYTES`，当前默认 512 KiB |
| 422 | 文件格式、节点数、URL 类型、层级或节点结构不受支持 |
| 423 | 另一设备正在同步或旧锁未过期；先等候，不要盲目强制同步 |
| 412 | 版本或临时上传基线过期，需重新读取远端再同步，不要直接重放旧文件 |
| E043 / E042 等 Failsafe | 扩展的大比例修改保护，先备份并确认合并/覆盖方向 |
| Worker 1102 | 可能达到 CPU/内存等资源限制，不等于每日请求额度耗尽 |

更详细的安全和服务端限制见 [SECURITY](SECURITY.md)、[协议说明](PROTOCOL.md)。

官方参考：[Floccus](https://floccus.org/)、[固定基线 WebDAV 适配器](https://github.com/floccusaddon/floccus/blob/c8ec55ee5e731206c6f2b34c48e8b4def47d0d5a/src/lib/adapters/WebDav.ts)。固定基线不是对永久最新版本的兼容性承诺。
