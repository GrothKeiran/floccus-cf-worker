# 账号与书签备份

## 设置账号

在 Worker 中配置：

| 名称 | 类型 | 内容 |
|---|---|---|
| `USERNAME` | Text | 用户名，例如 `owner` |
| `PASSWORD` | Secret | 5～256 字符的强密码 |

将 D1 以 `DB` 绑定到 Worker，保存部署后访问 `/init`。程序创建表结构，将用户名和带随机盐的 scrypt 密码哈希保存到 D1，并建立原账号的持久关联。

用户名支持 3～64 个英文字母、数字、点、下划线或短横线，首位为字母或数字，保存时统一转为小写。

## 配置 Floccus

| 配置项 | 内容 |
|---|---|
| 后端 | WebDAV → 自定义服务器 |
| URL | `https://你的Worker域名/dav/` |
| 用户名 | Worker 设置的 `USERNAME` |
| 认证密码 | Worker 设置的 `PASSWORD` |
| 文件名 | `bookmarks.xbel` |
| 文件类型 | XBEL |
| 加密口令 | 留空 |

多台浏览器填写相同的账号信息，分别选择对应的原生书签栏。先完成第一台同步，再配置其他浏览器，保持双向合并与安全保护。完整操作见 [Floccus 使用教程](FLOCCUS.md)。

## 修改用户名或密码

1. 在 Worker 修改 `USERNAME` 或 Secret `PASSWORD`，保存并部署。
2. 打开当前 Worker 的 `/init`。
3. 编辑各浏览器现有的 Floccus 同步配置，填写新账号信息，保留服务器地址和书签文件名。

程序更新关联的原账号，保留用户 ID、书签、目录、同步版本和删除记录。账号配置变化会撤销原登录会话、同步凭证、同步锁及临时上传；配置不变时重复访问 `/init` 保持现有凭证有效。

新用户名与其他账号冲突时操作停止，原账号和数据不变。删除关联账号后，程序不会自动重建账号或接管其他用户。高级管理员 API 恢复流程见[维护文档](DEPLOYMENT.md#安全恢复密码)；通过 API 单独改密码后应同步更新 Worker Secret，避免后续 `/init` 应用旧值。

## 导出书签备份

`/admin` 是一个可选备份工具，与日常同步流程无关：

1. 打开 `https://你的Worker域名/admin`。
2. 使用当前同步账号的用户名和密码登录。
3. 点击“下载备份 JSON”。
4. 保存文件，完成后退出登录。

备份包含当前账号的书签、目录、同步状态和删除记录，不包含账号密码、内部密钥或认证凭证。文件用于数据备份，**不是可直接导入浏览器的 HTML 书签文件**；备份与恢复范围详见[维护文档](DEPLOYMENT.md#备份)。

会话只保存在当前页面内存中，刷新或关闭后需重新登录。退出登录会撤销该备份会话，不影响 Floccus 的账户密码认证。备份包含私人网址，请保存在可信位置，不要上传公开仓库。
