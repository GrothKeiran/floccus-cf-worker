# 账号与访问管理

## 创建同步账号

安装时在 Worker 中设置：

| 名称 | 类型 | 内容 |
|---|---|---|
| `USERNAME` | Text | 用户名，例如 `owner` |
| `PASSWORD` | Secret | 14～256 字符的强密码 |

将 D1 数据库以 `DB` 绑定到 Worker，部署后访问 `/init`。程序创建表结构，并将用户名和带随机盐的 scrypt 密码哈希保存到 D1。内部安全密钥由程序生成和保存。

用户名支持 3～64 个英文字母、数字、点、下划线或短横线，首位为字母或数字，保存时统一转为小写。

## 在 Floccus 中使用

| 配置项 | 内容 |
|---|---|
| 后端 | WebDAV → 自定义服务器 |
| URL | `https://你的Worker域名/dav/` |
| 用户名 | 部署时设置的 `USERNAME` |
| 认证密码 | 部署时设置的 `PASSWORD` |
| 文件名 | `bookmarks.xbel` |
| 文件类型 | XBEL |
| 加密口令 | 留空 |

多台浏览器填写相同的账号信息，分别选择对应的原生书签栏。先完成第一台同步，再配置其他浏览器，保持双向合并及安全保护。完整操作见 [Floccus 使用教程](FLOCCUS.md)。

## 登录管理页面

在浏览器打开：

```text
https://你的Worker域名/admin
```

使用同步账号的用户名和密码登录。管理页面提供：

- 导出账号备份 JSON。
- 创建、查看和撤销独立应用密码。
- 退出当前管理会话。

管理会话仅保存在当前页面内存中，刷新或关闭页面后需重新登录。导出文件包含书签与同步状态，请妥善保存。

## 为浏览器设置独立应用密码

当需要单独撤销某台浏览器的访问权限，或者明确区分并发同步客户端时，可以使用独立应用密码。

1. 登录 `/admin`。
2. 在“可选：独立应用密码”填写设备名，例如 `Chrome-电脑A`。
3. 点击“生成应用密码”，保存显示的 `app_…` 密码。
4. 将该浏览器 Floccus 中的认证密码替换为此应用密码，其他配置保持不变。
5. 为其他需要独立管理的浏览器分别生成应用密码。

应用密码仅在创建时显示一次，丢失后应撤销并重新生成。设备列表显示已签发的应用密码，不列出账户密码模式下的内部同步上下文。

### 撤销的影响

- 撤销某个应用密码，只影响使用该应用密码的客户端，不删除书签。
- 撤销应用密码不影响使用账户密码的客户端。
- 要使共享账户密码失效，需要执行管理员密码重置；该操作会同时撤销此账号的所有会话、应用密码和旧同步锁。

同一个应用密码应分配给一台浏览器，避免多个客户端共用。账户密码模式按网络与浏览器上下文区分常见客户端，不能保证可靠的唯一设备身份；同出口、同浏览器的并发配置若需严格隔离，请使用独立应用密码，详见[协议说明](PROTOCOL.md#共享账户密码与可选设备凭证)。

## 修改用户名或密码

1. 在 Worker 修改 `USERNAME` 或 Secret `PASSWORD`，保存并部署。
2. 打开当前 Worker 的 `/init`。
3. 编辑各浏览器现有的 Floccus 同步配置，填写新的账号信息，保留服务器地址和书签文件名。

程序会更新关联的原账号，保留原用户 ID、书签、目录、同步版本和删除记录。账号配置有变化时，会撤销原有会话、应用密码、同步锁和临时上传；使用独立应用密码的浏览器需要重新签发凭证。

配置不变时重复访问 `/init` 不会更换密码哈希或撤销凭证。新用户名若与其他账号冲突，操作返回错误，原账号及凭证保留。

## 账号初始化与密码恢复

`USERNAME` / `PASSWORD` 是关联账号的配置来源。账号已经保存到 D1 后：

- 配置变化需在保存部署后访问 `/init` 才会应用，不会自动修改书签。
- 配置不变时重复访问 `/init` 保持现有凭证有效。
- 删除初始账号后，程序不会自动重新创建该账号。
- 如果使用管理员 API 重置密码，应同步更新 Worker 的 `PASSWORD`；之后再访问 `/init` 会应用 Worker 当前配置。

管理员密码恢复属于高权限维护操作，操作方法见[维护文档](DEPLOYMENT.md#安全恢复密码)。管理 API 及权限说明见[协议文档](PROTOCOL.md#管理-api)。账号恢复应保留原数据库，不以删除数据代替重置密码。
